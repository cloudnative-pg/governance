# Code of Conduct

CloudNativePG follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/master/code-of-conduct.md). <!-- wokeignore:rule=master -->

## Reporting

Report a violation to either address; both are read, and a reporter does
not have to pick the right one:

- **conduct@cloudnative-pg.io**, which reaches CloudNativePG.
- **conduct@cncf.io**, the CNCF Code of Conduct Committee, which is
  independent of this project. Use this one for a report concerning
  anyone in CloudNativePG's leadership, or whenever you would rather the
  project not read it first.

See [GOVERNANCE.md's Code of Conduct section](GOVERNANCE.md#code-of-conduct)
for who reviews a report, what responses are available, and when a matter
goes to the CNCF instead.
